# Материалы

Документы обучения, полученные не в виде записей: раздаточные материалы, конспекты,
описания упражнений, программы.

На каждый документ — пара файлов:

- оригинал в исходном формате (`.docx` и т. п.)
- читаемая версия `.md` с той же разметкой и указанием источника и автора
