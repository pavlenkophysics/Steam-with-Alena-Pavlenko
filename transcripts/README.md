# Транскрипты банного обучения Steamology

Склад транскриптов.

## Файлы

На каждую запись — пара:

- `ГГГГ-ММ-ДД-тема.raw.md` — сырой автотранскрипт, как есть, без правок
- `ГГГГ-ММ-ДД-тема.clean-ru.md` — вычитанная версия на русском: ошибки распознавания
  восстановлены по смыслу, расставлены реплики и абзацы, спорные места помечены

Если дата неизвестна — просто тема.
